3. NAVIDROME & OPENSUBSONIC API IMPLEMENTATION (`src/api.rs`, `src/models.rs`)
================================================================================
[IMPLEMENTED] Authentication:
              - Subsonic MD5 token authentication (`t = md5(password + salt)`, `s = random salt`, `v = 1.16.1`, `c = Ultrasonic`, `f = json`)
              - String ID handling everywhere (MD5/UUID strings, including `playQueue.current`, plus fallback numeric ID deserialization via `deserialize_string_id`)
[IMPLEMENTED] Multi-Library Support (Navidrome Priority):
              - `getMusicFolders` — Fetches all libraries accessible to the authenticated user
              - Multi-library visibility selector in Sidebar, Settings, and WebUI (users with access to multiple libraries can select one, multiple, or all libraries simultaneously)
              - Server-side multi-library filtering via repeated `musicFolderId` query parameters (`?musicFolderId=id1&musicFolderId=id2`) on all supported endpoints (`getAlbumList2`, `getArtists`, `getRandomSongs`, `getSongsByGenre`, `getStarred2`, `search3`)
[IMPLEMENTED] System & Server Capabilities:
              - `ping` — Connection & server version verification
              - `getOpenSubsonicExtensions` — Query server OpenSubsonic capabilities
              - `getScanStatus` — Navidrome extended scan status (`scanning`, `count`, `lastScan`, `folderCount`)
              - `startScan` — Trigger library scan with Navidrome `fullScan=true|false` support
[IMPLEMENTED] Music Browsing & Discovery:
              - `getAlbumList2` — Browse albums by `newest`, `recent`, `frequent`, `random`, `starred`, `alphabeticalByName`, `alphabeticalByArtist` (scoped by selected `musicFolderId`s)
              - `getAlbum` — Fetch album details and tracklist with OpenSubsonic metadata (`bitDepth`, `samplingRate`, `channelCount`, `replayGain`, `discNumber`, `bitRate`, `suffix`)
              - `getArtists` — Fetch ID3 artists grouped by index (scoped by selected `musicFolderId`s)
              - `getArtist` — Fetch artist details and discography
              - `getArtistInfo2` / `getAlbumInfo2` — Biography, album notes, MusicBrainz/Last.fm links
              - `getGenres` & `getSongsByGenre` — Genre list and genre-scoped songs (scoped by selected `musicFolderId`s)
              - `getRandomSongs` — Random songs mix (scoped by selected `musicFolderId`s)
              - `getStarred2` — Starred songs, albums, and artists (scoped by selected `musicFolderId`s)
              - `getTopSongs` — Artist top tracks
[IMPLEMENTED] Search:
              - `search3` — Unified search across Artists, Albums, and Songs (scoped by selected `musicFolderId`s)
[IMPLEMENTED] Playlists:
              - `getPlaylists` — List all user & public playlists
              - `getPlaylist` — View playlist tracks
              - `createPlaylist` — Create new playlist
              - `updatePlaylist` — Add tracks (`songIdToAdd`) and remove tracks (`songIndexToRemove`)
              - `deletePlaylist` — Delete playlist
[IMPLEMENTED] Media Retrieval, Streaming, & Downloading:
              - `stream` — Stream audio with configurable `format` (`raw`, `flac`, `opus`, `mp3`, `aac`) and `maxBitRate` (`0`, `320`, `256`, `192`, `128`, `96`, `64`), plus `timeOffset`
              - `download` — Navidrome enhanced download supporting Songs, Albums, and Playlists with configurable download `format` and `maxBitRate`
              - Auto-Download on Stream toggle (`config-auto-download-streamed`) — Automatically downloads tracks to local offline storage (`OfflineIndex`) when streamed once; subsequent plays use the local file directly
              - `getCoverArt` — Artwork fetching with local disk caching (`covers/`) and RGBA image decoding (`src/models.rs`)
              - `getLyricsBySongId` (OpenSubsonic structured synced lyrics) & `getLyrics` (classic fallback + LRC timestamp parser)
[IMPLEMENTED] Media Annotation, Scrobbling, & Queue Sync:
              - `star` / `unstar` — Favorite/unfavorite songs and albums
              - `setRating` — 1–5 star ratings on tracks
              - `scrobble` — Navidrome-compliant `submission=false` (Now Playing) on track start and `submission=true` at >=50% playback to update Navidrome play count & last-played timestamp
              - `getPlayQueue` / `savePlayQueue` — Server-side play queue synchronization (using string `current` ID)
              - `getShares` / `createShare` / `deleteShare` — Navidrome share link management

4. INTENTIONALLY EXCLUDED / NOT IMPLEMENTED
================================================================================
[EXCLUDED] Internet Radio (`getInternetRadioStations`, `createInternetRadioStation`, `updateInternetRadioStation`, `deleteInternetRadioStation`) — Excluded per user request ("No radio, no podcasts, just music").
[EXCLUDED] Podcasts (`getPodcasts`, `getNewestPodcasts`, `refreshPodcasts`, `createPodcastChannel`, `deletePodcastChannel`, `deletePodcastEpisode`, `downloadPodcastEpisode`) — Excluded per user request ("No radio, no podcasts, just music").
[EXCLUDED] Video / HLS (`getVideos`, `getVideoInfo`, `hls`, `getCaptions`) — Excluded (music-only player; also unimplemented in Navidrome).
[EXCLUDED] Chat (`getChatMessages`, `addChatMessage`) — Legacy Subsonic chat widget; not supported by Navidrome and not relevant to music playback.
[EXCLUDED] Directory Tree Simulation (`getIndexes`, `getMusicDirectory`) — Navidrome docs recommend ID3 browsing (`getArtists`/`getAlbumList2`) over simulated `/Artist/Album/Song` directory endpoints.
[EXCLUDED] Jukebox mode (`jukeboxControl`) — Server hardware audio output control; local Desktop/Mobile/WebUI playback is used instead.

5. NON-BLOCKING ASYNC ARCHITECTURE & SKELETON LOADERS
================================================================================
[IMPLEMENTED] Apple Music-Style Skeleton Shimmer Loaders (`ui/app.slint`):
              - Custom `SkeletonBlock` with smooth 250ms transition pulsing shimmer (`pulse-phase`)
              - Specialized view skeletons matching exact Apple Music layout geometry:
                * `TrackRowSkeleton` / `TrackTableSkeleton` (for Songs, Favorites, Search, and Genres)
                * `AlbumTileSkeleton` (for Featured & Album grid)
                * `AlbumRowSkeleton` (for Artist discography)
                * `AlbumDetailSkeleton` (large cover art + header details + 8 skeleton track rows)
                * `ArtistDetailSkeleton` (header + top 5 tracks skeleton + discography grid skeleton)
              - Responsive view loading states wired to `is-loading` property across all views (`listen_now`, `albums`, `album_detail`, `artists`, `songs`, `favorites`, `search`, `genres`, `playlists`)
[IMPLEMENTED] 100% Non-Blocking Asynchronous Network Architecture (`src/controller.rs`):
              - Zero synchronous HTTP network calls on the Slint UI thread (`ureq` offloaded to `std::thread::spawn` background workers)
              - Safe cross-thread event loop dispatch using `slint::invoke_from_event_loop` and `with_app_state`
              - Asynchronous catalog loading (`getAlbumList2`, `getRandomSongs`, `getArtists`, `getGenres`, `getPlaylists`, `getShares`, `getScanStatus`)
              - Asynchronous view navigation & sorting (`listen_now`, `albums`, `favorites`, `songs`, `change_album_sort`)
              - Asynchronous master-detail browsing (`open_album`, `open_artist`, `select_genre`, `run_search`, `select_playlist`)
              - Asynchronous background multi-track downloader (`download_album`, `download_selected_playlist`, `download_song`)
              - Asynchronous playlist & queue management (`create_new_playlist`, `add_current_song_to_playlist`, `remove_song_from_selected_playlist`, `delete_selected_playlist`, `save_queue_to_server`, `load_queue_from_server`)
              - Instant UI feedback with optimistic updates for stars & 1-5 ratings (`toggle_star`, `toggle_album_star`, `set_song_rating`)
              - Background server scan requests & share management (`trigger_server_scan`, `share_current_album`, `delete_share`)
[IMPLEMENTED] Progressive Cover Art Fetching & Decoding:
              - Covers resolve instantly from in-memory cache without stalling UI
              - Uncached covers fetched on background threads (`fetch_cover_art`), decoded, and loaded into Slint models dynamically without frame drops
[IMPLEMENTED] Non-Blocking Audio Streaming & Playback:
              - Clicking any track updates Now Playing bar immediately (<1ms) with title, artist, album, duration, and "BUFFERING..." badge
              - Audio stream bytes, synchronized lyrics, and scrobble notifications fetched concurrently on background worker threads
              - Generational playback tokens (`play_generation`) prevent race conditions when rapidly changing tracks
              - Scrobble at 50% playback mark executes asynchronously in background to avoid any audio or UI progress hitching
